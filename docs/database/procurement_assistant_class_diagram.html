核心建模原则

  • • 每张持久化表抽象为一个类，表名保留为类名。
  • • 只画关键字段和字段类型，完整字段说明以 Excel 为准。
  • • 不创建物理外键；跨表归属与状态转换由 Delegate + 短事务保证。

运行时关系

  • • 一个会话可以产生多个场景和 Run，但同一会话通过租约串行执行。
  • • 场景等待点签发一组互斥 Action，消费时必须复查用户、场景和状态。
  • • Trace Span 按 trace_id / parent_span_id 组成完整调用树。

Checkpoint 边界

  • • Checkpoint 使用 thread_id + scenario_instance_id 隔离会话和场景。
  • • blobs 保存 channel 序列化值，writes 保存任务级 pending writes。
  • • 当前以 langgraph-checkpoint-postgres 3.1.1 为结构基线，OpenGauss 仍需实测验收。
